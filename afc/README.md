# Anantapur Football Club — Cinematic Website

React + Vite project for AFC.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Vercel deployment

Import this repository with the project root set to the folder containing `package.json` and `index.html`.

- Framework preset: Vite
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

The `src/main.jsx` entry point is required by `index.html`.

## Notes

The registration form is a frontend demonstration. It does not securely store registrations or process payments. Connect a backend, authentication, server-side validation, and a payment provider before using it for live registrations.
